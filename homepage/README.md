# 딜 모아 홈페이지

프로젝트 루트에서 `python3 -m http.server 8000`을 실행한 뒤 http://localhost:8000/homepage/ 에 접속합니다. 기존 `products.json`과 `coupons.json`을 읽습니다.

상품 가격과 쿠폰은 USD 기준입니다. 장바구니는 코인 할인 후 금액에 쿠폰을 적용하고, 남은 금액을 기준으로 카드 할인 조건을 확인합니다. 실제 쇼핑몰의 적용 조건은 다를 수 있습니다. 저장 상품과 장바구니는 브라우저의 localStorage에 보관되며 다른 사용자와 공유되지 않습니다. 쇼핑몰의 접근 제한으로 링크 가격 자동 조회는 지원하지 않으므로 가격을 직접 입력합니다.
